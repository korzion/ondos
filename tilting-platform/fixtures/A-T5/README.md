# A-T5 Safe state

Requirement: A-R5

**Method:** Stop the command stream; send the software E-stop; press the physical E-stop button.

**Pass if:** Below 1° within 1 s after the command timeout; software E-stop levels and locks; the button cuts servo power and sets is_e_stop.
