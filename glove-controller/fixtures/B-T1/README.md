# B-T1 Rate and delay

Requirement: B-R1

**Method:** 60 s at 1 m; the receiver counts packets and echoes every 10th one.

**Pass if:** 50 ± 2 Hz, ≤ 2 % loss, 95th percentile of RTT/2 ≤ 30 ms.
