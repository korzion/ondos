# B-T4 Calibration and signs

Requirement: B-R3

**Method:** calibrate_request raised (long press, calibrate_glove, or the receiver board on Dec 4) with the hand in a position; tilt forward, back, left and right; calibrate again in another position.

**Pass if:** The held position reads 0 ± 1°; each tilt changes the right axis with the right sign; after the second calibration the new position reads 0 ± 1°.
