# B-T2 Vibration patterns

Requirement: B-R2

**Method:** The receiver sends the Haptic patterns from haptic_cases.csv; the glove logs arrival and motor-on times.

**Pass if:** ≤ 100 ms from arrival to motor on; with is_vibration_enabled = false the motor stays off.
