# C-T1 Position accuracy

Requirement: C-R1

**Method:** Ball in a small ring on a sheet printed with the markers and crosshairs at 9 known positions; plate flat and on a 10° wedge.

**Pass if:** Error ≤ 3 mm at ≥ 20 Hz (edit_state = hand_present while a hand places the ball is expected).
